이야기의 4막 구조

발단(인물·배경 소개, 사건의 씨앗) → 전개(문제 발생, 해결 시도) → 절정(가장 긴장된 순간) → 결말(해결, 인물의 변화). 이 순서가 이야기의 뼈대.

오늘의 과제

인물 만들기

입체적 인물 = 원하는 것 + 두려워하는 것 + 비밀(약점). 평면적 인물 = '착하다', '나쁘다'처럼 한 마디로 설명됨. 성격은 말과 행동으로 드러내야 함.

오늘의 과제

이름   날짜

스스로 점검 — 다 썼으면 하나씩 확인해요

  • ☐ 소개 단락에 인물의 성격을 보여주는 말(대화)이나 행동이 1개 이상 있는가

배경 묘사하기

Show vs Tell — Tell을 Show로 바꾸기

Tell(직접 서술): '화가 났다' / Show(보여주기): '주먹을 꽉 쥐고 발을 구르며 방문을 쾅 닫았다'. Show의 도구: 구체적 행동, 대화, 감각 묘사.

주장과 의견의 차이

의견: '나는 고양이가 좋다' (반박 불필요). 주장: '학교에서 동물을 키워야 한다' (근거 필요, 반박 가능). 주장은 반박 가능한 구체적인 하나의 입장.

오늘의 과제

내가 강하게 믿는 것 3가지를 주장 형태로 쓰기. 각 주장이 반박 가능한 형태인지 확인 (모든 사람이 동의하면 주장 아님).

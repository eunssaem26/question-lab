## 1장: 설계 철학 및 포지셔닝

### 1.1 핵심 명제 — '회화'가 아니라 '문해력'

영어권 한국어 시장의 거의 모든 서비스(TTMIK·Duolingo·LingoDeer·세종학당·서강대)는 **의사소통(말하기) 중심**이다. 서강대조차 "수업의 절반 이상이 말하기"를 표방한다. **텍스트를 비판적으로 읽고 생각을 글로 구성하는 능력**을 정면으로 다루는 자기주도 상품은 사실상 부재하다.

생각하는 글밭은 이미 한국어 원어민용 **5영역 문해력 진단 엔진**(어휘력·사실적 이해·추론적 이해·비판적 이해·구조 파악)과 **단계별 평가 준거틀**을 보유하고 있다. 영어권 커리큘럼은 이 자산을 KFL(Korean as Foreign/Heritage Language) 학습자에게 이식하여, "한국어로 **읽고 쓰는 사고력**"을 가르치는 유일한 문해력 특화 서비스로 포지셔닝한다.

### 1.2 시장 공백과 우리의 자리

리서치가 확인한 두 가지 공백을 정조준한다.

1. **'중급의 벽' 이후가 시장 공백.** Duolingo·LingoDeer는 B1(TOPIK 3급)에서 끝나고, TTMIK도 산출 연습 부족이 공인된 약점이다. 중·고급 읽기/쓰기를 체계적으로 가르치는 자기주도+피드백 결합 상품이 거의 없다. → **우리의 무게중심은 중급·고급에 둔다.** 초급은 진입로일 뿐, 차별화는 중급의 벽을 넘기는 데서 나온다.

2. **쓰기 피드백 루프가 최대 페인포인트.** "쓰기는 혼자서 맞는지 확인 불가능한 유일한 영역"이라는 인식이 확고하고, TOPIK 쓰기 첨삭이 고가 패키지의 셀링포인트로 팔린다. → **진단 엔진 + 평가 준거틀로 이 피드백 루프를 자동화·체계화**하는 것이 우리의 해자(moat)다.

### 1.3 설계 원칙

| # | 원칙 | 내용 |
|---|---|---|
| 1 | **문해력 엔진 재사용** | 원어민용 5영역(VOC/LIT/INF/CRT/STR)을 KFL 맥락에 맞게 재정의하여 그대로 사용한다. 새 엔진을 만들지 않는다. |
| 2 | **진단 기반 배치** | 학년·나이가 아니라 진단 결과로 레벨을 배치한다. heritage는 기능별 비대칭이 크므로 **읽기·쓰기 독립 진단**을 적용한다. |
| 3 | **이원 트랙, 조기 합류** | heritage와 L2의 출발 조건이 다른 **초급에서만 트랙을 분리**하고, 능력이 수렴하는 **중급부터 단일 커리큘럼으로 합류**시킨다. |
| 4 | **TOPIK/CEFR 정합** | 모든 레벨을 TOPIK 등급과 CEFR에 명시 매핑한다. 고급은 자연스럽게 TOPIK II 쓰기 대비로 연결한다. |
| 5 | **성장 지향** | 부족함을 지적하지 않고 "다음 단계로 가려면 무엇을" 안내한다(원어민 준거틀과 동일 철학). |

## 2장: 레벨 체계

### 2.1 3티어 ↔ TOPIK ↔ CEFR ↔ 어휘량 매핑

업계 관행대로 **3분법(초/중/고)을 표면 레벨**로 쓰되, 내부적으로 **TOPIK 6등급에 대응하는 6개 세부단계**로 세분한다.

| 티어 | 세부단계 | TOPIK | CEFR | 어휘량(누적) | 핵심 문해 능력 |
|---|---|---|---|---|---|
| **초급** | 초급 1 | 1급 | A1 | ~800 | 한글 해득, 단문 읽기, 자기소개 쓰기 |
| **초급** | 초급 2 | 2급 | A2 | 1,500~2,000 | 일상 텍스트 읽기, 짧은 메모·일기 쓰기 |
| **중급** | 중급 1 | 3급 | B1 | 3,000~4,000 | 친숙한 주제 단락 독해, 문단 단위 쓰기 |
| **중급** | 중급 2 | 4급 | B2 | 5,000~6,000 | 신문·수필 독해, 실용문(이메일·설명문) 쓰기 |
| **고급** | 고급 1 | 5급 | C1 | 8,000~10,000 | 학술 텍스트 독해, 논증 에세이 작성 |
| **고급** | 고급 2 | 6급 | C2 | 12,000+ | 사설·전문 텍스트 비판적 분석, 모어 화자급 쓰기 |

### 2.2 트랙 분리·합류 구조

```
  [L2 트랙]                              [Heritage 트랙]
  순수 외국인 학습자                      재외동포 (가정 내 구어 보유)
       │                                      │
  ┌────────────┐                        ┌────────────┐
  │ L2 초급 1  │ (한글·기초문법부터)     │ Heritage   │ (한글·구어 스킵,
  │  (A1)      │                        │ 문어 입문  │  문어체·정서법·어휘 집중)
  ├────────────┤                        ├────────────┤
  │ L2 초급 2  │                        │ Heritage   │ (격식체·문어 어휘·
  │  (A2)      │                        │ 문어 기초  │  단락 쓰기로 가속 브리지)
  └─────┬──────┘                        └─────┬──────┘
        │                                     │
        └──────────────┬──────────────────────┘
                       ▼  ◀── 합류 지점 (배치 진단으로 진입 레벨 결정)
              ┌────────────────┐
              │   중급 1 (B1)   │  ← 이 지점부터 단일 커리큘럼
              ├────────────────┤
              │   중급 2 (B2)   │
              ├────────────────┤
              │   고급 1 (C1)   │
              ├────────────────┤
              │   고급 2 (C2)   │
              └────────────────┘
```

**합류 원리:** 초급의 출발 조건(한글 해득 여부, 구어 보유 여부)만 트랙별로 다르다. 중급 이상에서 요구되는 **문어 독해·논리적 쓰기 능력은 두 집단 모두에게 새로운 학습**이므로, 합류시켜 같은 커리큘럼을 적용하는 것이 효율적이며 리서치 결론과도 일치한다.

## 3장: 트랙 정의

### 3.1 L2(순수 외국인) 트랙 — 초급 전용

| 항목 | 내용 |
|---|---|
| 대상 | 한국어 노출이 없던 영어권 학습자. 한글부터 시작 |
| 출발점 | 한글 자모·음운 규칙 → 기초 조사·시제 → 단문 읽기·쓰기 |
| 강점/약점 | 문법은 체계적으로 쌓이나 어휘·읽기 속도가 느림 |
| 진단 적용 | 4기능이 비교적 균등 상승 → **단일 레벨 배치**로 충분 |
| 이수 후 | 중급 1로 합류 |

### 3.2 Heritage(재외동포) 트랙 — 초급 전용

| 항목 | 내용 |
|---|---|
| 대상 | 가정에서 한국어 구어를 들으며 자란 재외동포. 듣기·발음은 우수하나 **읽기·쓰기가 최대 약점** |
| 출발점 | 한글·기초 회화 **스킵**. 정서법(받아쓰기)·문어체 어휘·격식체/존댓말 체계·문어 통사부터 |
| 강점/약점 | 구어 유창성 보유(평폐쇄음 변별 우위), 그러나 구어-문어 격차가 큼. 학습 동기가 낮은 경향 → **외적 구조(과제·진단·피드백)가 더 중요** |
| 진단 적용 | 기능별 비대칭(듣기 B2 / 쓰기 A2 식) → **읽기·쓰기 독립 진단 필수.** 단일 레벨 테스트 작동 안 함 |
| 설계 특징 | 구어 자산을 지렛대로 삼아 **가속 브리지**(2단계)로 빠르게 중급 진입. 동기 유지 위해 짧은 과제·즉시 피드백 강화 |
| 이수 후 | 중급 1로 합류(단, 읽기·쓰기 레벨이 다르면 영역별로 다른 진입점 허용) |

### 3.3 합류 지점의 배치 로직

- L2·Heritage 모두 초급 이수 시 **중급 진입 배치 진단**을 본다.
- 종합 레벨이 아니라 **읽기·쓰기 각각의 독립 레벨**로 배치한다(heritage 비대칭 흡수).
- 예: heritage 학습자가 읽기 중급 1, 쓰기 초급 2로 진단되면 → 읽기는 중급 1, 쓰기는 초급 2 보충을 병행한다.

## 4장: 레벨별 커리큘럼 명세

각 레벨은 **목표 · 어휘 · 문법/문형 · 읽기(텍스트 유형·길이) · 쓰기(산출물) · 문해력 5영역 성취 · 진입/이수 기준**으로 기술한다.

### 4.1 L2 초급 1 (A1 / TOPIK 1) — `L-B1`

- **목표:** 한글 완전 해득 → 기본 문장 산출 → 자기 정보 읽고 쓰기
- **어휘:** ~800 (인사·숫자·가족·음식·일상 사물)
- **문법/문형:** 한글 자모·음운, 은/는·이/가·을/를, 이에요/예요, 있다/없다, 현재시제 -아/어요, 부정 안/못
- **읽기:** 표지판·메뉴·자기소개문 등 1~2문장 실용 텍스트
- **쓰기:** 자기소개 3~4문장, 빈칸 채우기, 단어→문장 확장
- **문해력 영역:**
  - VOC: 학습 어휘의 사전적 뜻 직접 파악
  - LIT: 한 문장에서 명시 정보 찾기
  - INF: (최소) 그림+문장 단서로 의미 짐작
  - CRT: 해당 없음(맹아 단계)
  - STR: 문장 부호·줄바꿈 인식
- **이수 기준:** 한글 무오류 읽기, 800어휘 70%, 자기소개문 작성

### 4.2 L2 초급 2 (A2 / TOPIK 2) — `L-B2`

- **목표:** 일상 텍스트 읽기 → 짧은 글(메모·일기) 쓰기
- **어휘:** 1,500~2,000 (쇼핑·교통·날씨·취미·감정 기초)
- **문법/문형:** 과거 -았/었-, 미래 -(으)ㄹ 거예요, 연결어미 -고/-지만/-아서, 존댓말 기초(-(으)세요), 관형형 -(으)ㄴ/-는
- **읽기:** 문자메시지·짧은 안내문·일기 등 3~5문장 텍스트
- **쓰기:** 일기·메모 5~8문장, 시간 순서로 하루 서술
- **문해력 영역:**
  - VOC: 문맥에서 낯선 일상 어휘 뜻 추론
  - LIT: 짧은 글의 누가/언제/무엇 사실 확인
  - INF: 인물 감정·다음 행동 짐작
  - CRT: 글쓴이의 좋다/싫다 태도 구분(초보)
  - STR: 시간 순서·간단한 나열 구조 인식
- **이수 기준:** 5문장 텍스트 요지 파악, 일기 쓰기, 2,000어휘 70% → **중급 진입 배치 진단**

### 4.3 Heritage 초급 — 문어 입문 `H-B1` / 문어 기초 `H-B2`

> 구어를 보유한 학습자를 위한 **가속 브리지**. 한글 해득·기초 회화는 점검만 하고, 곧바로 구어-문어 격차 해소에 집중한다.

**H-B1 — 문어 입문**
- **목표:** 들리는 말과 쓰는 글의 차이 인식 → 정서법 정확도 확보
- **어휘:** 구어 어휘를 **표기**로 전환(받아쓰기), 문어체 기본 어휘 도입
- **핵심:** 받아쓰기, 음운 규칙의 표기 반영(연음·경음화), 띄어쓰기, 반말↔존댓말↔격식체(하십시오체/해요체) 체계화
- **읽기:** 익숙한 구어 내용을 글로 옮긴 짧은 텍스트
- **쓰기:** 들은 것 받아쓰기 → 짧은 메시지 정서법 교정
- **문해력 영역:** VOC(구어어휘의 문어 표기), LIT(글에서 정보 확인), STR(문장 경계·띄어쓰기)
- **이수:** 받아쓰기 정확도 80%, 존댓말 격식 구분

**H-B2 — 문어 기초**
- **목표:** 문어체 어휘·통사 확장 → 단락 단위 쓰기 진입
- **어휘:** 문어 빈출 어휘, 한자어 기초, 추상 어휘 입문
- **핵심:** 문어 연결어미(-며/-으며, -지만), 격식체 종결(-습니다/-ㅂ니다), 인용 -고 하다, 단락 구성 기초
- **읽기:** 안내문·설명문 등 비구어 텍스트 한 단락
- **쓰기:** 한 단락(4~6문장) 설명/서술
- **문해력 영역:** VOC(문어·한자어 어휘), LIT/INF(단락에서 정보·의도 파악), STR(단락 구조)
- **이수 기준:** 단락 독해, 단락 쓰기 → **중급 진입 배치 진단**(읽기·쓰기 영역별)

### 4.4 중급 1 (B1 / TOPIK 3) — `M-I1` 〔합류〕

- **목표:** 친숙한 사회적 주제의 긴 텍스트 독해 → 문단 단위 논리적 쓰기
- **어휘:** 3,000~4,000 (사회·문화·시사 기초, 한자어 체계 확장)
- **문법/문형:** 간접화법(-다고/냐고/자고 하다), 연결어미 확장(-는데/-더니/-거든), 추측 -(으)ㄹ 것 같다/-나 보다, 격식체/비격식체 전환
- **읽기:** 수필·뉴스 기사·설명문 (여러 단락, 300~500자)
- **쓰기:** 실용문(이메일·설명문) 한 편, 경험·의견 문단
- **문해력 영역:**
  - VOC: 다의어·한자어를 문맥에서 변별
  - LIT: 여러 단락에 흩어진 정보 통합
  - INF: 생략된 정보·글쓴이 의도 추론
  - CRT: 주장과 근거 구분, 사실/의견 변별
  - STR: 문단 간 관계(원인-결과, 비교) 파악
- **이수 기준:** 500자 텍스트 요지·세부 파악, 의견 문단 작성, 4,000어휘 70%

### 4.5 중급 2 (B2 / TOPIK 4) — `M-I2` 〔합류〕

- **목표:** 신문·수필 독해 → 실용문·설명문 능숙 작성 (취업·진학 문턱)
- **어휘:** 5,000~6,000 (시사·직무·추상 개념)
- **문법/문형:** 피동·사동, -도록/-게 하다, 양보 -더라도/-(으)ㄴ들, 격식 문어 표현, 담화 표지(따라서·반면)
- **읽기:** 신문 기사·칼럼·설명적 수필 (500~800자)
- **쓰기:** 설명문·요약문·격식 이메일, 자료 기반 정보 전달 글
- **문해력 영역:**
  - VOC: 추상·전문 어휘, 관용 표현 일부
  - LIT: 긴 텍스트의 핵심·세부 위계 파악
  - INF: 함축·전제 추론, 필자 관점 파악
  - CRT: 논거의 타당성·편향 평가(초급)
  - STR: 글 전체 구조(서론-본론-결론) 분석
- **이수 기준:** 800자 텍스트 비판적 요약, 설명문 작성, 6,000어휘 70%

### 4.6 고급 1 (C1 / TOPIK 5) — `M-A1` 〔합류〕

- **목표:** 학술·전문 텍스트 독해 → **논증 에세이 작성** (TOPIK II 쓰기 연계 시작)
- **어휘:** 8,000~10,000 (학술·전문·관용어·속담)
- **문법/문형:** 고급 문어 표현, 명사화 -(으)ㅁ/-기, 인용·논증 담화 구조, 문체(문어/구어) 구분
- **읽기:** 학술문·논설문·사설 (800~1,200자)
- **쓰기:** 600~700자 논리 에세이(서론-전개-결론), 주장+근거+예시 구성
- **문해력 영역:**
  - VOC: 관용어·속담·전문 어휘의 함축
  - LIT: 복잡한 학술 텍스트의 정보 구조화
  - INF: 다층적 함의·논리적 비약 추론
  - CRT: 논증의 타당성·오류·관점 비판적 평가
  - STR: 논증 구조(전제-결론, 반론-재반론) 해부
- **이수 기준:** 학술문 비판적 독해, 600자 논증 에세이(준거 채점 통과)

### 4.7 고급 2 (C2 / TOPIK 6) — `M-A2` 〔합류〕

- **목표:** 모든 텍스트의 비판적 분석 → 모어 화자급 논증·서술
- **어휘:** 12,000+ (전 영역, 문체적 뉘앙스)
- **문법/문형:** 문체 변용 자유 구사, 고급 수사·문어 관습 완전 습득
- **읽기:** 전문 학술서·사설·문학 (제한 없음)
- **쓰기:** 700자+ 논증·비평·분석문, 독자·목적에 맞는 문체 조절
- **문해력 영역:**
  - VOC: 모어 화자급, 미묘한 어감·문체 차이 활용
  - LIT/INF: 함축·아이러니·전제까지 완전 파악
  - CRT: 텍스트의 이데올로기·전제·수사 전략 비판
  - STR: 복합 텍스트 구조 재구성·평가
- **이수 기준:** 전문 텍스트 비판 분석, 700자+ 비평문 작성

## 5장: 문해력 5영역의 KFL 적용

원어민 엔진의 5영역을 KFL 맥락에서 **무엇이 달라지는지**만 명시한다(가중치는 원어민과 동일하게 출발, 운영 데이터로 보정).

| 영역 | 원어민 정의 | KFL 적용 시 차이 |
|---|---|---|
| **VOC** 어휘력 | 어휘 뜻·문맥 추론 | **한자어·외래어 표기, 구어↔문어 어휘 전환**이 추가 부담. heritage는 구어 어휘 보유분을 표기로 연결 |
| **LIT** 사실적 이해 | 명시 정보 파악 | 텍스트 자체가 외국어 → **읽기 속도·해독 부하**가 변별의 큰 변수 |
| **INF** 추론적 이해 | 생략·함축 추론 | 문화적 배경지식 부족이 추론을 막음 → **문화 스키마 보충** 필요 |
| **CRT** 비판적 이해 | 주장·근거 평가 | 사고력 자체는 L1에서 전이됨 → **언어 장벽만 낮추면 빠르게 상승**(영어권 성인 학습자의 강점) |
| **STR** 구조 파악 | 글 구조 분석 | 한국어 특유의 결속 표지(담화 표지·연결어미) 학습이 핵심 |

> **시사점:** 영어권 성인 학습자는 CRT(비판적 사고)를 모어에서 이미 보유한 경우가 많다. 우리의 차별화는 "사고력은 있는데 한국어 텍스트를 못 읽는" 학습자의 **언어 장벽만 제거**해 CRT를 한국어로 발현시키는 데 있다.

## 6장: 진단·배치 연계

- **초급 진입:** 트랙 선택(heritage/L2)은 간단한 사전 설문(가정 내 한국어 사용 여부)으로 분기.
- **중급 합류 배치:** 기존 진단 엔진(`writing-app/src/lib/diagnosis/engine.ts`)을 재사용하되, **읽기·쓰기 독립 진단**을 적용해 heritage 비대칭을 흡수한다.
- **영역별 독립 수준:** 현 엔진은 이미 영역별 독립 레벨과 편차 알림(편차 ≥3단계)을 산출한다 → heritage의 "듣기↔쓰기 격차" 안내에 그대로 활용 가능.
- **레벨 코드 매핑:** 본 커리큘럼의 6세부단계를 진단 엔진의 레벨 인덱스와 연결하는 매핑 테이블을 `english-curriculum.json`의 `level_mapping`에 둔다.

---

## 7장: 산출물 로드맵

1. **지문 뱅크(passages)** — 기존 `item-bank/.../passages.json` 모델을 KFL 난이도로 확장(graded reader 자산화. TTMIK Stories가 읽기 단독 상품으로 성립함을 증명).
2. **문항 뱅크(items)** — 레벨×영역별 KFL 문항. 3번 과제(문항 풀 확대)와 동일 스키마 사용.
3. **쓰기 첨삭 준거** — 고급의 600~700자 논증 에세이를 평가 준거틀로 자동 채점·피드백(우리의 핵심 차별화, TOPIK II 쓰기 대비와 연결).
4. **다국어 UI** — 초급 해설은 영어 병기, 중급 이상 점진적 한국어화.

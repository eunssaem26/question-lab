영어권 순수 외국인(L2) 학습자를 위한 트랙 설계. 목표는 **새 콘텐츠를 최소로 만들면서** 기존 작문 커리큘럼·진단 엔진·AI 피드백 자산을 그대로 재사용하는 것.

---

## 1. 설계 원칙 (리서치 근거)

경쟁 8개 서비스 분석에서 도출된, 생각하는 글밭이 이겨야 할 자리.

- **'중급의 벽' 이후를 공략** — Duolingo·LingoDeer는 B1에서 끝나고 중·고급 읽기·쓰기 자기주도 상품은 시장 공백. 여기가 주전장.
- **쓰기 피드백 루프 = 최대 자산** — "쓰기는 혼자 맞는지 확인 불가"가 확고한 페인포인트. 이미 가진 단계별 평가 준거틀 + AI 첨삭이 이걸 자동화.
- **'회화'가 아닌 '문해력' 포지셔닝** — 경쟁사는 전부 말하기 중심. 비판적 독해→논증적 쓰기를 정면으로 다루는 서비스는 부재. TOPIK II 쓰기와 자연 연결.
- **heritage / L2 이원 트랙** — 재외동포는 한글·구어를 스킵하고 문어·작문만 필요, L2는 한글부터. 초급에서 분리, **중급 이상에서 합류**.

## 2. 레벨 아키텍처 — TOPIK ↔ 글밭 단계 매핑

| 구간 | TOPIK / CEFR | 어휘(추정) | 글밭 단계 | 핵심 문해 능력 |
|---|---|---|---|---|
| 초급 | 1급 · A1 | ~800 | **신규 `L2-초급1` (stage 101)** | 한글 해득 · 자기소개 · 생존 문장 · 기본 조사 |
| 초급 | 2급 · A2 | 1.5~2천 | **신규 `L2-초급2` (stage 102)** | 시제 · 존댓말 기초 · 짧은 메모·일기 쓰기 |
| 중급 | 3급 · B1 | 3~4천 | 기존 `1~2단계` (합류) | 문장→중심문장·뒷받침·단락 · 소개글 |
| 중급 | 4급 · B2 | 5~6천 | 기존 `3~4단계` | 서론-본론-결론 · 설명문 · 독후감 |
| 고급 | 5급 · C1 | 8~10천 | 기존 `5~6단계` | 이야기 구성 · 논설문(주장·근거·반박) |
| 고급 | 6급 · C2 | 12천+ | 기존 `7단계` | 에세이·칼럼·제안서 · TOPIK II 쓰기 대비 |

> **핵심:** 신규로 만들 콘텐츠는 **초급 2개 모듈뿐**. 중급 이상은 기존 1~7단계를 그대로 재사용(영어 스캐폴딩만 추가)하므로 제작 부담이 대폭 감소.

## 3. 이원 트랙 모델 — 분리 후 합류

```
L2 (순수 외국인):   [초급1 한글·생존] → [초급2 기초문장·쓰기] ─┐
                                                              ├─→ 기존 1~7단계 (문장→에세이)
Heritage (재외동포): 진단으로 바로 배정 ──────────────────────┘
```

- **Heritage**: 지금처럼 7단계 진단으로 바로 배정.
- **L2 초급**: 아직 문장 진단 이전 수준이라 **진단을 건너뛰고 초급1부터** 시작 → 초급2 수료 시 기존 진단으로 편입 단계 판정 (결정 D2).

## 4. 신규 L2 초급 온램프 — 구조

유일하게 새로 만드는 부분. 세종학당·TTMIK 공통 순서를 문해력(읽기·쓰기) 중심으로 재편. 각 모듈 12차시로 기존 단계와 동일 리듬.

### L2-초급 1 — 한글에서 첫 문장까지 (TOPIK 1 · A1)
목표: 한글을 읽고 쓰며, 나를 소개하는 문장을 만든다.

1. 한글 모음·자음 (읽기) 2. 한글 받침·조합 (쓰기) 3. 인사와 자기소개 4. 이것은 ~입니다 5. 조사 은/는, 이/가 6. 숫자·날짜·시간 7. 조사 을/를, 에/에서 8. 지금 ~해요 (현재 시제) 9. 나를 소개하는 짧은 글 10. 내 하루 쓰기 11. 복습·미니 과제 12. 루브릭 종합 평가

### L2-초급 2 — 문장에서 짧은 글까지 (TOPIK 2 · A2)
목표: 과거·미래를 표현하고, 하나의 주제로 5~6문장 글을 쓴다.

1. 과거 시제 ~았/었어요 2. 미래·계획 ~ㄹ 거예요 3. 존댓말과 반말 기초 4. 이유 ~아서/어서 5. 연결 그리고·하지만 6. 형용사로 꾸미기 7. 메모·메시지 쓰기 8. 간단한 일기 쓰기 9. 좋아하는 것 소개 글 10. 주말 이야기 쓰기 11. 복습·미니 과제 12. 루브릭 종합 평가 → 진단 편입

**영어 스캐폴딩:** 지시문·설명은 영어 우선(한국어 병기), 예문·산출은 한국어. AI 피드백은 영어로 첨삭 이유 설명, 교정 예시는 한국어.

## 5. 기존 시스템에 그대로 붙는다

신규 초급 수업도 기존 `LessonConfig` 구조를 그대로 씀 → 수업(write)·AI 피드백·대시보드가 코드 수정 없이 작동. `track: "l2"` 필드로 구분.

```ts
// src/prompts/l2-beginner1/index.ts — 초급1 · 3차시 예시
{
  track: "l2",
  stage: 101, lesson_num: 3, lesson_id: "03",
  lesson_title: "인사와 자기소개 (Greetings & Introductions)",
  lesson_summary: "안녕하세요 · 저는 ~입니다 · 만나서 반갑습니다.",
  assignment: "Write 3 sentences introducing yourself in Korean: name, country, greeting. (이름·나라·인사)",
  criteria: "C1: 인사말이 있는가 / C2: '저는 ~이에요' 문형 / C3: 나라 정보",
  pass_rule: "C1·C2 충족, C3 확인",
  not_evaluated: "조사 미세 오류, 존댓말 등급",
  model: HAIKU, max_tokens: 900, is_rubric: false,
}
```

## 6. 결정사항 (은쌤 승인 완료)

| | 결정 | 확정 |
|---|---|---|
| **D1** | 트랙 구분 | `LessonConfig.track: "heritage" \| "l2"` 필드 추가, 초급은 별도 stage 키(101/102). heritage 기존 그대로 |
| **D2** | L2 초급생 진단 | 초급1~2는 진단 없이 순서 진행 → 초급2 수료 시 기존 7단계 진단으로 편입 |
| **D3** | 영어 스캐폴딩 | 초급은 지시문 영어 우선(한국어 병기)+예문/산출 한국어, AI 피드백 영어 설명. 중급부터 한국어 비중↑ |
| **D4** | 제작 순서 | 배선(코드) → 초급1 → 초급2 → 중급 합류 스캐폴딩 |

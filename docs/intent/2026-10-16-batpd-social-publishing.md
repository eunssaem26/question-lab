# 의도 문서 — 밭피디가 인스타·스레드·유튜브를 맡는다

작성 2026-10-16 · 상태: **승인됨 (2026-10-16, A~G 모두 추천대로)**

## 목표

은쌤이 영상·카드를 만들어 두기만 하면, 밭피디가 채널별 글을 붙여 승인을 받고 **버튼 한 번으로 인스타·스레드·유튜브에 올린다.** 은쌤이 휴대폰으로 파일을 옮기거나 캡션을 다시 치는 일을 없앤다.

## 정한 것 (은쌤 결정)

1. **올리기 전 승인은 슬랙 버튼 한 번.** 승인 없이는 아무것도 나가지 않는다. *(밭피디 SOUL "은쌤 검수 없이 내보내지 않는다"와 같은 뜻)*
2. **오픈 순서표를 먼저 끝내고, 그다음 토스 앱 릴스 2편**(오늘의 AI 단어 QR판 → 셀프케어 체크 QR판).
   - 오픈 순서표 남은 12개는 기존 `video/data/posts.json` 순서 그대로: 캐릭터 캐러셀 10개 → 열 명이 하는 일 → 진단 받기
   - 참고: 지금까지 올린 12개(브랜드 3 · 파노라마 3 · 게임 카드 6)와 남은 12개가 모두 3의 배수라, 이 순서면 그리드가 안 밀린다.

## 기본값 (나중에 감으로 바꿀 수 있음)

- 승인 요청 메시지는 5줄 규칙(결론 → 한 일 → 은쌤이 할 일 → 다음 시각)
- 승인 뒤 올리기 실패 시 1번만 다시 시도하고, 안 되면 실패 이유를 #미디어실에 남김
- 스레드 글은 인스타 캡션을 500자 안으로 줄인 것, 유튜브 제목은 40자 안
- 올린 기록은 `operations/social/state.json` 하나에 (기존 `operations/instagram/state.json`은 가져와 합침)

## 은쌤이 직접 해야 하는 것 (제가 대신 못 함)

로그인·권한 허용·토큰 발급은 은쌤 손으로만 할 수 있어요. 화면은 제가 옆에서 안내해요.

1. 메타 개발자 앱 만들기 — `operations/instagram/SETUP.md` 3~6단계 (7월에 멈춘 곳) + 같은 앱에 **스레드** 추가
2. 구글 클라우드에서 유튜브 업로드 권한 허용 1회 (+ 감사 신청서)
3. 토큰은 `secret-ask` 가려진 입력창으로만 넣기
4. (선택) 서치 콘솔에 인스타 속성 추가 — 구글 검색에서 들어온 클릭을 밭피디 주간 보고에 넣을 수 있음

## 기술 선택 (제 몫, 참고용)

- 임시 공개 보관은 E 답에 따른다.
- 인스타 릴스·유튜브는 이 컴퓨터의 파일을 바로 올린다.
- 발행 스크립트는 `scripts/social/`에 두고, 밭피디는 이 스크립트만 실행한다. 승인 장치는 A 답에 따른다.

## 검증 방법

1. `node scripts/social/queue.mjs --status` — 대기열 순서가 위 2번과 같은지
2. 토큰 확인: `node scripts/social/verify.mjs` — 세 채널 계정 이름만 찍힘(토큰 값은 안 찍힘)
3. **첫 실발행 1건**(필로 캐러셀)을 은쌤이 버튼으로 승인 → 인스타·스레드에 실제로 뜨는지 은쌤 눈으로 확인
4. 토스 앱 릴스 1편이 세 채널에 올라가고, 유튜브는 비공개로 들어갔는지 확인
5. 수요일 10:00 크론이 #미디어실에 제안 1건을 사람 손 없이 올리는지

## 작업 순서 (임시)

1. 대기열 파일 만들기 + 오픈 순서표·영상 2편·소개곡 5편 등록 (토큰 없이 지금 가능)
2. 은쌤과 메타 앱·스레드 연결 → 인스타·스레드 발행 스크립트 → 첫 실발행
3. 구글 연결 → 유튜브 업로드
4. 밭피디 SOUL에 SNS 운영 몇 줄 + 크론 등록 + motion-prompt 스킬 연결
5. AKM 운영 계획 문서의 "API 자동 발행 금지" 줄 갱신

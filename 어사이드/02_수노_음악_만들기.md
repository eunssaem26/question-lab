# 수노로 릴스 배경음악 만들기 (어사이드에게) — 매번 쓰는 틀

은쌤 인스타 릴스(@eunssaem26, 생각하는 글밭)는 목소리 없이 자막 카드만 나오는 영상이라 배경음악이 필요하다.
**영상을 만들기 전에** 음악을 먼저 만든다. 곡마다 제목·스타일·구조는 클로드 코드가 이 파일 아래 「이번 곡들」에 적어 둔다.

## 꼭 지킬 것
- https://suno.com 에서 은쌤 계정으로 만든다. 로그인이 안 돼 있으면 멈추고 은쌤에게 알린다.
- **Instrumental(연주곡)을 반드시 켠다.** 가사가 들어가면 안 된다.
- 결제·플랜 변경·크레딧 구매 화면이 뜨면 아무것도 누르지 말고 멈춘 뒤 은쌤에게 알린다.
- 만든 곡을 공개(Publish/Share)하지 않는다. 비공개 그대로 둔다.

## 순서 (곡마다)
1. Create → **Custom** 모드 → Instrumental 켜기.
2. 아래 「이번 곡들」의 **Title**·**Style**을 그대로 붙여 넣는다. **Lyrics** 칸에는 구조 태그만 붙여 넣는다.
3. Create를 누르고 두 곡이 다 만들어질 때까지 기다린다.
4. 두 곡의 **처음 25초**를 들어 보고 하나를 고른다. 고르는 기준:
   - 처음부터 바로 소리가 나는 곡(앞 2~3초가 조용하면 탈락)
   - 사람 목소리·허밍이 섞이지 않은 곡
   - 「분위기」 설명에 더 가까운 곡
5. 고른 곡을 **MP3로 내려받아** `~/Downloads/` 에 **파일 이름을 `<번호>.mp3`** 로 저장한다(예: `1105.mp3`). 이름을 바꿀 수 없으면 원래 이름 그대로 두고 어느 곡이 어느 번호인지 알려 준다.

## 끝나면 은쌤에게 이렇게만 알려 줘
- 번호마다: 저장한 파일 이름, 두 곡 중 어느 쪽을 골랐고 왜 골랐는지 한 줄
- 못 만든 곡이 있으면 이유

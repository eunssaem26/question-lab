# 네이버 블로그 「은혜있는 Study」 → 「생각하는 글밭」 정리 (어사이드에게)

은쌤 네이버 블로그(https://blog.naver.com/bluesk211)의 이름을 바꾸고 카테고리를 새로 짜는 일이다.
앞으로 이 블로그에 AI 리터러시·글쓰기·독서 교육 글을 쓴다. **예전 글 105편은 하나도 지우지 않고** 「지난 기록」과 「믿음의 기록」으로 옮겨 둔다.

## 꼭 지킬 것
- **글을 지우지 않는다.** 카테고리를 지울 때도 그 안에 글이 0편인지 먼저 확인한다. 글이 남아 있으면 지우지 않는다.
- 글의 공개 범위(전체 공개 등)와 본문은 바꾸지 않는다. 카테고리만 옮긴다.
- **블로그 주소(bluesk211)는 바꾸지 않는다.** 주소는 평생 한 번만 바꿀 수 있어 은쌤이 따로 정한다.
- 화면이 설명과 다르거나, 하위 카테고리로 옮기는 기능이 안 보이면 추측하지 말고 멈춘 뒤 화면 상태를 알려 준다.
- 저장 버튼은 단계마다 누르고, 다음 단계로 가기 전에 블로그 첫 화면에서 반영됐는지 본다.

## 1. 블로그 이름과 소개 바꾸기
블로그 첫 화면 → 관리 → 기본 설정 → 블로그 정보.
- **블로그명:** `생각하는 글밭`
- **소개글:** 아래를 그대로 넣는다.
  ```
  1999년부터 아이들을 가르친 은쌤과 AI 친구 필로가 읽기·쓰기·AI 활용 이야기를 씁니다. Where Thoughts Grow
  ```
- **별명:** `은혜있는` → `은쌤` (프로필의 별명 칸. 은쌤은 모든 곳의 별명을 「은쌤」으로 통일한다)
- **블로그 주제:** 지금 「교육·학문」이다. 그대로 둔다.
- 저장.

## 2. 새 카테고리 만들기
관리 → 메뉴·글·동영상 관리 → 블로그(카테고리 관리).
맨 위부터 이 순서가 되게 한다. (「」 안이 이름, ↳는 하위 카테고리)

```
「생각하는 글밭 이야기」        ← 새로 (공지·소개용)
「필로의 AI 교실」              ← 새로 (AI 리터러시)
「글쓰기 교육」                 ← 새로
「독서·문해력」                 ← 새로
─── 구분선 (지금 있는 구분선을 여기로 옮긴다)
「믿음의 기록」                 ← 지금 「Bible study」의 이름을 바꾼다
─── 구분선 (없으면 새로)
「지난 기록」                   ← 새로 만든 상위 카테고리
   ↳ 은쌤과 함께 독서
   ↳ 책나눔
   ↳ Memories
   ↳ 보물창고
   ↳ 맛있는 기억
   ↳ 즐거운 베이킹~
   ↳ 좋은 글 수집 일기
   ↳ 지구를 위하여
   ↳ [블챌] 주간일기 챌린지
```

- 기존 카테고리 아홉 개는 **이름을 바꾸지 말고** 「지난 기록」 밑으로 끌어 넣어 하위 카테고리로 만든다. 그러면 안에 있는 글이 그대로 따라온다.
- 새 카테고리 네 개는 전체 공개로 만든다. 글이 없어도 괜찮다.
- 저장.

## 3. 신앙 글을 「믿음의 기록」으로 옮기기
「Bible study」에 있던 10편은 이름만 바뀌었으니 그대로 둔다. 아래 8편은 다른 카테고리에 있으니 「믿음의 기록」으로 옮긴다.

## 4. 확인
- 블로그 첫 화면 이름이 「생각하는 글밭」, 별명이 「은쌤」인지
- 카테고리 목록이 위 순서인지, 「지난 기록」 밑에 아홉 개가 있는지
- 「믿음의 기록」 글 수가 **18편**인지
- 전체 글 수가 **105편** 그대로인지 (줄었으면 바로 멈추고 알린다)

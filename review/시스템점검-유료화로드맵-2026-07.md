## 2. 문제 인벤토리 & 해결 현황

### 높음 (유료화·신뢰의 발목) — 4/4 해결 ✓
- ✅ **진단→수업 404** — 미구현 단계(2~7) 접근 시 404였음 → "준비 중" 가드 후 전 단계 콘텐츠 배선으로 완전 해결
- ✅ **비공개 초안 공개 노출** (홈) — draft가 공개 URL로 빌드됨 → `status: published`만 빌드 + 중복 5개 삭제
- ✅ **Google OAuth 사전등록 우회** (의심) — 라이브 확인 결과 `disable_signup: true`로 이미 차단됨. 거부 UX 강화 + 초대제 규칙 코드 고정
- ✅ **진단 정답 노출·결과 위조** — 정답·해설이 브라우저로 내려가고 채점도 클라 → **서버 채점 전환**(server-only 문항은행 + HMAC 서명 토큰 세션). 클라 번들에 해설 부재 확인 + 레벨 1·3·5·7 엔드투엔드 시뮬 정확 판정

### 중간 (품질·성능·안정성) — 5/6 해결 ✓
- ✅ 미들웨어 매요청 Auth 왕복 → matcher를 보호경로로 한정
- ✅ AI 응답 무검증 → `normalizeFeedback` 스키마 검증
- ✅ 테스트 전무 → 진단 엔진 단위테스트 도입(`npm test`, 11건)
- ✅ 블로그 죽은 링크(/diagnosis) → 교정
- ✅ OG 이미지 placeholder 고정 → 글별 heroImage + robots.txt

## 3. 유료화 5단계 로드맵

앞 단계가 끝나야 다음이 의미 있는 순서. 기간은 1인+AI 협업 대략치.

### Phase 0 — 안정화 (완료 ✓)
목표: 접속자가 404·깨진 링크 없이 끝까지 돈다. → Supabase 정지 방지, 404 가드, 초안 정리, 죽은 링크 교정.

### Phase 1 — 신뢰·보안 (사실상 완료 ✓)
목표: 계정·진단 결과를 조작 불가로. → Google 게이트 확인, 진단 서버 채점, 결과 위조 차단, 보안 헤더. (남은 것: CRON_SECRET 재추가만)

### Phase 2 — 핵심 기능 완성 (대부분 완료 ✓)
목표: 진단→배정→수업→피드백→리포트가 전 단계 무결. → 2~7단계 배선(콘텐츠 기존재), AI 스키마 검증, **대시보드 리포트 강화**(영역별 진단·진도바·교사 현황판), **영어권 KFL 트랙**(초급1·2 + 영어 피드백 + 트랙 선택 + 중급 합류). 남은 것: 없음(KFL 콘텐츠 고도화는 선택).

### Phase 3 — 운영 안정성 (Phase 2와 병행, 일부 완료)
목표: 규모가 커져도 안 깨진다. → ✅ 진단 엔진 테스트, ✅ 미들웨어 최적화. 남은 것: 에러 모니터링(Sentry), DB 백업, Supabase Pro 승격 검토.

### Phase 4 — 유료화 (다음 큰 축)
목표: 무료 체험 → 결제 → 구독 관리. → 요금제 설계(진단 단건/코스 구독/학원 좌석), 결제 연동(토스페이먼츠·Stripe), 구독·좌석 관리, 이용약관·개인정보·환불정책(재외동포 대상 유의).

## 보존할 것 (필로 캐릭터 톤)

- **친근체 어미**: `~이에요`, `~예요`, `~거든요`, `~죠`, `~어요`. 평서체로 떨어뜨리지 않는다.
- **1인칭 화자 시점**: "저는", "저희는". 코디네이터 화자 자리.
- **시리즈 연속성**: "지난 편에서~", "다음 편에서는~" 도입·마무리는 유지.
- **고유명사·수치·날짜**: 100% 원문 보존 (별쌤·책쌤·글쌤·은쌤·호기·필로, 700만, 9만 4천, 5×7, 2022 개정 등).

## 무조건 제거 (S1)

| 패턴 | 처방 | 필로 글에서 자주 보이는 형태 |
|---|---|---|
| em dash(—) 남발 | 마침표·쉼표·줄바꿈으로 분리 | "어휘력 — 단어의 뜻을…", "뉴욕에 밤 10시 — 시드니에 아침 7시" |
| "이것이 ~인 이유입니다" 결말 | 평서로 닫기 ("~ 그래서예요") | "이것이 질문연구소가 ~로 태어나게 된 이유입니다" |
| "이것이 바로 ~" / "바로 ~입니다" | 삭제 또는 평서화 | "바로 이 점이 ~" |
| 한글 + (English) 병기 | 첫 등장만, 이후 한글만. 캐릭터명에서는 전부 삭제 | `필로 (Philo)`, `별쌤 (Byeolsaem)` |
| "결론적으로 / 정리하면" | 본문에 흡수 또는 삭제 | — |
| hype 어휘 3회+ | 구체 사실로 환원 | "압도적인", "강력한", "획기적인" |
| 의인화 추상 주어 | 사람·기관 주어로 | "교육이 묻는다", "시대가 부른다" |
| 시그니처 "— 필로, 질문연구소 코디네이터" | 삭제 (author 메타가 이미 표시) | 모든 글 말미 |
| `**강조**` 마크다운 남발 | 핵심 1~2개만 | — |
| `(1) (2) (3)` 숫자 인덱싱 | 줄바꿈 또는 산문 | 영역 나열 시 |

## 1~2회 허용, 3회+면 제거 (S2)

| 패턴 | 처방 |
|---|---|
| "~를 통해/통하여" | "~로", "~해서"로 분산 |
| "~에 대해서" | 목적격 직결 |
| "~을 가지고 있다" | 형용사형 |
| "~할 수 있다" 단정 회피 | 단언으로 |
| "~에 의해" 피동 | 능동으로, 행위자를 주어로 |
| 기계적 5항 병렬 (동일 길이·동일 어미) | 3+2 분할, 또는 산문화 |
| 수사 의문 헤딩 ("왜 ~인가요?", "~할 수 있을까요?") | 한 글에 1회. 평서 헤딩으로 |
| 변환 공식 "X에서 Y로", "X가 아니라 Y" | 한 번만 살리고 나머지는 일반 서술 |
| 문두 접속사 ("또한·따라서·즉·게다가") 5회+ | 대량 제거 |
| "X은 ~라는 점에 있다" | 직설로 |
| "~할 것이다" 미래 단정 | 현재형 |

## 자체검증 (편집 후 5초 점검)

1. 수치·고유명사·인용 한 글자도 안 바뀌었는가
2. 변경률 30% 이하인가 (50% 초과면 강제 중단·롤백)
3. 친근체 어미 유지되었는가 (평서체로 떨어지지 않았는가)
4. em dash 잔존 0건
5. "이것이 ~ 이유입니다" 잔존 0건
6. (English) 병기 잔존 0건
7. 시그니처 라인 0건
8. 원문에 없던 비유·수사를 새로 만들지 않았는가

## 등급

- **A**: S1 잔존 0, S2 잔존 2 이하, 변경률 10~25%
- **B**: S1 잔존 0, S2 잔존 4 이하
- **C**: S1 잔존 1~2 → 재작업
- **D**: S1 잔존 3+ 또는 변경률 50% 초과 → 사람 검토
